# Data Architecture & Schemas

This directory manages the state of the data pipeline, housing the JSON ingestion manifests and the resulting structured datasets.

## Pipeline Flow

1. `2025-2026_playoff_vids.json` acts as the single source of truth for the ingestion engine.
2. The ingestion script outputs `raw_live_2026.csv`.
3. The NLP scoring engine reads the raw data and outputs `scored_live_2026.csv`.

## Schemas

### `raw_live_2026.csv`
Contains the raw output from the Whisper/YouTube API pipeline.
* `video_id` (str): The YouTube UUID.
* `team` (str): Categorical team identifier (e.g., "Knicks", "Cavaliers").
* `stage` (str): Playoff chronological tag (e.g., "R1G1", "Reg Season - Magic (Opponent)").
* `won_championship` (int): Target variable (0 or 1). Default 0 for live runs.
* `transcript` (str): The raw, unformatted text block.

### `scored_live_2026.csv`
Contains the transformed feature vectors generated by the RoBERTa model.
* Includes all columns from the raw schema.
* `confidence` (float): Probability score [0.0 - 1.0]
* `content` (float): Probability score [0.0 - 1.0]
* `neutrality` (float): Probability score [0.0 - 1.0]
* `frustration` (float): Probability score [0.0 - 1.0]
* `upset` (float): Probability score [0.0 - 1.0]
* `anxiety` (float): Probability score [0.0 - 1.0]
* `surprise` (float): Probability score [0.0 - 1.0]

## Fault Tolerance
The directory relies on a hidden checkpointing file (`.ingestion_checkpoint`) to prevent duplicate API calls and handle rate-limiting during large data pulls.
